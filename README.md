# Mutagen 同步面板

基于 [mutagen](https://mutagen.io) 的本地 ↔ 服务器文件同步面板。底层全部调用 mutagen 命令行，面板只负责把命令变成按钮，并实时显示每个同步会话的状态。

* 零依赖：只需要 Node.js 18+，不用 `npm install`
* 关闭面板不影响同步：同步由 mutagen 守护进程在后台执行

## 启动

1. 下载并解压 mutagen（Windows 选 `mutagen_windows_amd64_vX.Y.Z.zip`），`mutagen.exe` 和 `mutagen-agents.tar.gz` 要放在同一目录。
2. 将本目录的 `config.example.json` 复制为 `config.json`（已有配置时无需复制），把 `mutagen` 改成 `mutagen.exe` 的完整路径（JSON 里反斜杠要写两个）：

   ```json
   "mutagen": "D:\\mutagen\\mutagen_v0.18.1\\mutagen.exe"
   ```

   也可以先启动面板，在「更多 → 设置」里修改，保存后立即生效。
3. Windows 双击 `mutagen-panel启动.bat`；macOS / Linux 在本目录执行 `npm start`（或 `node server.js`）。浏览器会自动打开 `http://127.0.0.1:7790`。

Windows 桌面图标：在项目目录运行 `.\mutagen-panel启动.bat --create-desktop-shortcut`，会创建或更新带双向同步图标的桌面快捷方式。`.bat` 文件本身不能单独设置图标，请使用该快捷方式启动，不要把启动脚本单独复制到桌面。移动项目目录后，在新目录重新运行此命令即可更新快捷方式。

## config.json

| 字段 | 说明 |
| --- | --- |
| `mutagen` | mutagen 可执行文件路径。写命令名（如 `mutagen`）时从 PATH 查找，相对路径相对于本目录 |
| `host` / `port` | 面板监听地址，默认只监听本机 `127.0.0.1:7790`；端口被占用时自动顺延 |
| `openBrowser` | 启动后是否自动打开浏览器 |
| `pollIntervalMs` | 刷新会话状态的间隔，默认 1000 毫秒 |
| `ssh` / `sshKeygen` | ssh、ssh-keygen 命令，默认用系统自带的 OpenSSH |
| `editors.vscode` / `editors.idea` | 「用 VS Code / IDEA 打开」使用的命令或完整路径 |
| `localRoot` | 默认本地根目录。新建会话时选好服务器目录，本地目录自动填成「根目录\\服务器目录名」；留空则沿用上次创建时的位置 |

## 功能

* **当前服务器**：首页顶部显示当前服务器的别名、登录账号（user@IP:端口）、连接状态、主机名、系统、延迟、磁盘使用（取自服务器上的 `df -P -k`，使用率与 `df -h` 一致，点击查看所有分区，/boot/efi 这类启动分区会标明无需关注）和该服务器上的同步会话数，每 30 秒自动检测一次。点名称切换服务器，切换结果写入 config.json 的 `defaultHost`，新建会话、免密向导、文件管理都默认用它。github.com 这类 Git 托管主机不会被当成服务器
* **服务器文件管理**：左侧目录树（自动展开到当前目录）和快速访问（主目录、根目录、同步会话目录），中间是带大小、修改时间、权限、所有者的文件列表（可排序、筛选、显示/隐藏点文件），右侧是详情和文本预览（最多 256 KB，支持 UTF-8 / GBK）。可以复制完整路径、`主机:路径`、文件名、scp 下载命令，以及同步会话里对应的本地路径；能下载文件、删除文件或文件夹（右键「删除…」或 Delete 键，弹窗确认后永久删除，不进回收站；`/`、`/` 下的一级目录、主目录和同步会话的服务器目录不允许删除），在某个目录打开服务器终端，或把目录直接建成同步会话。底栏显示当前目录所在磁盘的使用情况。支持右键菜单、多选（Ctrl / Shift）和快捷键（Enter 打开、Backspace 上一级、Ctrl+C 复制路径、Ctrl+L 输入路径、F5 刷新、/ 筛选）。面板对每台服务器只保持一条 SSH 连接（10 分钟不用自动断开），所以只有第一次打开需要握手，之后翻目录很快
* **会话卡片**：服务器端、本地端的路径（长路径中间省略，点击复制）、连接状态、文件数和大小，最近同步时间。鼠标移上去出现快捷工具栏（同步、暂停、用 IDE 打开、服务器终端），右键卡片是完整操作菜单，单击卡片打开详情
* **命令面板（`Ctrl+K`）**：搜索会话或命令，回车直接执行；输入「会话名 + 操作」可一步到位，例如「网关 vs」用 VS Code 打开网关服务
* **新建 / 编辑会话**：从 `~/.ssh/config` 选主机，远程目录和本地目录都可以浏览选择；选好服务器目录后自动填写本地目录和名称，记住最近用过的服务器目录，`Ctrl+Enter` 提交，实时显示等效 mutagen 命令；卡片菜单里可「以此配置新建会话」
* **状态提醒**：出现冲突、报错时面板内提示，标签页标题和图标显示角标；可在设置里开启桌面通知（面板不在前台时弹出）
* **同步方式**：双向（安全 / 服务器优先 / 本地优先）、服务器 → 本地、本地 → 服务器，单向可选镜像
* **忽略规则**：常用规则一键添加，可选忽略 `.git`
* **操作**：立即同步、暂停 / 恢复、重置同步历史、用服务器覆盖本地、用本地覆盖服务器，以及全部、按分组批量操作
* **冲突处理**：详情里逐个选择保留哪一边，另一边的版本先移到备份目录再同步，不直接删除
* **分组**：拖动卡片排序，拖到分组标签上移动分组
* **SSH 免密登录向导**：生成密钥、写入 `~/.ssh/config`、打开终端上传公钥（只输一次密码）、测试免密
* **快捷入口**：在资源管理器、VS Code、IDEA、本地终端中打开本地目录，或打开服务器终端并进入远程目录
* **其他**：命令日志、石墨风格浅色 / 深色主题、卡片 / 列表视图、筛选（`/`）、新建（`N`）

## 数据位置

本机配置 `config.json` 和运行数据 `data/` 已通过 `.gitignore` 排除，不会提交到 Git 仓库。

* `data/panel.json`：会话显示名称、分组、排序（mutagen 自身的会话数据在 `~/.mutagen`）
* `data/conflict-backups/`：处理冲突时移走的本地副本
* 服务器上的 `~/.mutagen-panel-trash/`：处理冲突时移走的服务器副本

## 常见问题

* **提示 Permission denied**：服务器还不能免密登录，用「更多 → SSH 免密登录向导」配置。
* **首次创建会话很慢**：mutagen 第一次连接某台服务器时要上传 agent（约 10 MB），之后就快了。
* **想开机就同步**：在顶部守护进程菜单里选「登录 Windows 时自动启动」，不打开面板也会同步。
